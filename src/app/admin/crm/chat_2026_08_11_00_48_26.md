2. **deepseek**: To check for TypeScript errors in your project, you can use the TypeScript compiler (`tsc`). Here are the steps to identify and resolve TypeScript errors:

### 1. **Run the TypeScript Compiler**
Execute the following command in your project's root directory (where `tsconfig.json` is located):

```sh
npx tsc --noEmit
```
- `--noEmit` ensures the compiler only checks for errors without generating output files.

### 2. **Check Errors in Real-Time (IDE)**
If you're using an IDE/editor with TypeScript support (e.g., VS Code), errors will typically appear:
- **Underlined in red** in your code.
- In the **"Problems" panel** (`Ctrl/Cmd + Shift + M` in VS Code).

### 3. **Common TypeScript Errors**
Here are frequent TypeScript issues and fixes:

#### a. **Type Mismatch**
```ts
let num: number = "hello"; // Error: Type 'string' is not assignable to type 'number'.
```
**Fix:** Ensure correct types or use type assertions (if intentional):
```ts
let num: number = 42; // or
let strNum: number = parseInt("hello");
```

#### b. **Undefined/Null Checks**
```ts
function greet(name: string) {
  return `Hello, ${name.toUpperCase()}`;
}
greet(null); // Error: 'name' is possibly 'null'.
```
**Fix:** Add a check or use optional chaining (`?.`):
```ts
function greet(name: string | null) {
  return `Hello, ${name?.toUpperCase() ?? 'guest'}`;
}
```

#### c. **Missing Properties**
```ts
interface User {
  id: number;
  name: string;
}

const user: User = {}; // Error: Missing 'id' and 'name'.
```
**Fix:** Provide all required properties:
```ts
const user: User = { id: 1, name: "Alice" };
```

### 4. **Strict Mode**
If your `tsconfig.json` has `strict: true`, additional checks are enabled. Common strict-mode errors:
- **Implicit `any`**: Add explicit types or disable with `"noImplicitAny": false`.
- **Undefined checks**: Use optional properties (`prop?: string`) or null checks.

### 5. **Debugging Tips**
- **Focus on the first error**: Later errors may cascade from the initial one.
- **Use `tsc --traceResolution`** to debug module path issues.
- **Check `tsconfig.json`**: Ensure `include`/`exclude` paths are correct.

### Example `tsconfig.json`
```json
{
  "compilerOptions": {
    "target": "ES6",
    "module": "commonjs",
    "strict": true,
    "esModuleInterop": true
  },
  "include": ["src/**/*.ts"]
}
```
